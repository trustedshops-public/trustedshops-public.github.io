# trustedshops-public.github.io

Our OpenSource projects landing page.

## Development

Use **Yarn** for this repository (do not use npm).

```bash
yarn install
yarn dev
yarn build
yarn lint
yarn lint:fix
yarn format:check
yarn format
```

### Repository Metadata

The repository list is built from `public/repos-metadata.json`, which the app fetches at startup. The file is required: without it the page shows an error and no repositories. Repositories are sorted by their most meaningful activity date (latest release or main branch commit).

The file is git-ignored, so it is not committed. It is generated by the `repos-metadata` CircleCI workflow, which runs the generator, saves the JSON as an artifact, and deploys the site with it. The workflow runs when the `generate-repos-metadata` pipeline parameter is `true`, which the daily schedule sets.

For local development, generate the file before `yarn dev` or `yarn build`:

```bash
GITHUB_TOKEN=<your-token> yarn metadata
```

Requires a GitHub Personal Access Token with `repo:status` scope (to read repository data).
